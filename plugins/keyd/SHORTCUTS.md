## Mac Keyboard Shortcuts
  ⌥ ⌫                Delete the previous word
  ⌘ ⌫                Delete to the start of the line (Files: move to trash; Thunderbird: delete the message)
  ⌘ L                Address bar (in browsers; Files: type a path)
  ⌘ ,                The app's settings (Ctrl+,; not in the terminal)
  Enter              Rename file (in Files; F2 too)
  ⌘ O                Open file (in Files)

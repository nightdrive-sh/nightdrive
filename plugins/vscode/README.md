# VS Code

Visual Studio Code from Microsoft's own repository, set up to run natively on Wayland: sharp text and the right scaling, no XWayland.

- Hyper C opens VS Code, or brings it to the front if it's already open. `code .` in a terminal opens the current folder.
- Updates come with the rest of the system (`nightdrive update`), from Microsoft's repository.

Homepage: https://code.visualstudio.com
Keys: Hyper C

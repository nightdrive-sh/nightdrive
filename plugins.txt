# Optional parts. install.sh installs the Default on ones and Tailscale, Mail and Deck (ALWAYS there) without asking
# (--choose asks; --with/--without/--all/--none), the launcher lists them under System › Install and `nightdrive plugins`
# in a terminal, so what was skipped can be added later. The desktop hides a part that isn't installed: the launcher
# (Plugins.has), the top bar ("needs" in topbar/modules.jsonc), the keybindings (hypr/bindings.lua) and their lines in
# SHORTCUTS.md (an {id} at the end).
#
# This file holds the one-line parts (web apps, an app from dnf or Flathub), with their page in docs/plugins/<id>.md. A
# part with files of its own (a top bar module and menu, keys, a service, commands) is a folder, plugins/<id>/ (or
# ~/.local/share/nightdrive/plugins/<id>/ for one from elsewhere: `nightdrive plugins add GIT-URL`), with these fields in
# its plugin.conf as key=value lines: plugins/README.md explains them and the folder's other files. Ids are unique across
# both, and an external plugin can't take an id the repo has. `nightdrive plugins off ID` hides an installed part as if
# it weren't installed and stops its folder's units; `on` undoes it.
#
# id|Name|Lucide icon|One-line description|Default (on/off)|Installer|Installed when this shell test succeeds|Group
#   Installer: `flatpak APP-ID` (Flathub, per user), `webapp URL` (a Chromium app window named after the Name column), or
#   any other shell command; run in the repo root. A part that needs a script of its own is a folder (its install.sh).
#   Group: where it is listed (launcher and install.sh):
#     app          Nightdrive's own app (Mail, Deck): comes with every install and isn't listed in Install. `nightdrive
#                  update` installs a new one on an existing install once (~/.local/state/nightdrive/apps-offered), never
#                  again after it was removed. Only for a plugin folder, and a new app is decided one by one: part of
#                  Nightdrive, or bloat that belongs in Recommended.
#     recommended  Install › Recommended: an app or service Nightdrive sets up (its own launcher level, a top bar module,
#                  keys, config). A plain app without any of that isn't listed: Install › Software has it.
#     webapp       Install › Webapp, under "Ready-made": a web app with a keybinding
#     plugin       Install › Plugins: a feature of the desktop itself, not an app of its own
# install.sh installs them after everything else, after the plugin folders (in the order `nightdrive plugins` lists them).
